Cómo encajan

El proyecto separa tres responsabilidades. Conocer el límite entre ellas evita confundir dónde vive cada regla.

  • estructuras → los TAD propios. No conocen el dominio: son genéricos (<T>, <K, V>).
  • modelo → los datos del negocio. No valida reglas ni usa estructuras propias salvo ListaEnlazada para historiales.
  • servicio → la lógica (Banco, ServicioPuntos, Comisiones, Reloj). Crea y modifica el modelo.
  • interfaz → la UI JavaFX. Main abre el login y el dashboard; las vistas consultan Banco y reciben DTOs.

Estado del proyecto

  • Java 21 + Maven; JavaFX en uso con vistas programáticas (sin FXML).
  • Hay UI completa, 8 TADs y 89 pruebas JUnit.
  • El entrypoint real es interfaz.Main (aplicación JavaFX).
  • Estas guías son análisis estático: no ejecutan ni modifican el código.
